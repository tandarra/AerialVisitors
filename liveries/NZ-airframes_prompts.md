# NZ-airframes: base airframe prompts

One plain base airframe per physical type flown by New Zealand's scheduled airlines. Approve these first, then repaint each into airline liveries using the approved image as the reference.

Paste into the Gemini app, one image per prompt. Check the result against the **Check** line before approving.
